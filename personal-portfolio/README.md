# 🌐 My Personal Portfolio

Welcome to my personal portfolio! I'm Metsnanat Berhanu, a 3rd-year Computer Science student at St. Mary's University with an interest in web development, software engineering, and UI/UX design.

I created this portfolio to introduce myself, share some of the projects I've worked on, and showcase my skills and learning journey in tech.

## ✨ Features

- About Me: A little introduction about my background, interests, and goals.
- Skills: A section showing the programming languages, frameworks, databases, and tools I have been learning and working with.
- What I Do: An overview of my interests in frontend development, backend development, web development, and UI/UX design.
- My Projects: A collection of my projects with their technologies and live demos.
- Certifications: Some of the certificates I've earned in Data Science, Cybersecurity, and UI/UX Design.
- Contact Section: Links to my email, LinkedIn, and GitHub so people can easily reach me.
- Dark and Light Mode: Switch between two themes.
- Responsive Design: The website adjusts to different screen sizes.
- Animations: Includes smooth animations and interactive elements.
