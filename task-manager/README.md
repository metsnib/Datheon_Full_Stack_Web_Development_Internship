# ✅ Metsni – Task Manager

Metsni is a task management app I built using HTML, CSS, and JavaScript. It helps users organize their daily tasks, set priorities, track progress, and manage their work in one place.

I wanted to build something practical and interactive while improving my JavaScript skills and learning how to manage data in the browser.

## 🌟 Features

- Add Tasks: Create tasks with a title, description, category, priority, and due date.
- Edit Tasks: Update task details whenever needed.
- Delete Tasks: Remove tasks, with an option to undo within 5 seconds.
- Task Categories: Organize tasks into Work, Personal, Study, Health, and Finance, or create your own categories.
- Task Priorities: Set priorities to High, Medium, or Low.
- Task Progress: Track completed, active, and overdue tasks.
- Search Tasks: Quickly find tasks using the search bar.
- Filter Tasks: View all, active, completed, or overdue tasks.
- Sort Tasks: Organize tasks by due date, priority, name, or creation date.
- Drag and Drop: Rearrange tasks by dragging them into your preferred order.
- Dark and Light Mode: Switch between different themes.
- Sound Effects: Get a small sound when completing or deleting tasks.
- Animations: Enjoy confetti effects when completing tasks.
- Backup and Restore: Export and import tasks using JSON files.
- Local Storage: Tasks are saved in the browser, so they remain available after refreshing or reopening the app.
- Responsive Design: Works on desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM Manipulation
- Local Storage
- HTML5 Drag and Drop API
- Web Audio API
- Canvas API

## 🚀 How to Run

1. Clone this repository or download the project.
2. Open the project folder in VS Code.
3. Open index.html in your browser.

No additional installation or build tools are required.
